Arc-Length Parameterized Interpolating Splines

With Stephen M. Watt · Presented at ICMS 2026

An iterative method for computing a spline that exactly interpolates a set of points while being parameterized by true arc length — meaning the parameter directly reflects distance traveled along the curve, not just an approximation of it. This matters for applications like handwriting recognition and path planning, where the same shape traced at different speeds should still produce a consistent representation. The method works in any dimension and converges to a good approximation in just a couple of iterations for most shapes tested.

Right now I'm working on proving that this iterative algorithm actually converges — and ideally, that the result is unique. Empirically it converges quickly on every shape we've tested so far, but a formal proof is still an open problem.
